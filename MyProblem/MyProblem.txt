
ClaimsController will have below endpoints: 

/claim-search GET API to search claims by passing MSISDN, IMEI and all currently supported search criteria for newclaims structure.

/claim POST Create claim from mini app as well as from Vodasure for IAA policies. This API will send details about policy, customer, incident details and other required details for creating claim with initial status in system.

/claims GET Get all claims. 

/claim/{id} GET Get claim by claim ID. NEW 

/claim/{id} PUT Update claim details for given identifier. New 

/claim/{id} PATCH Patch required data for given claim. New 

/claim/:id/status PATCH Update only status of claim. New 

/claim/payment-details POST Capture bank details for cash claims. New. 

/claim/beneficiary-details POST Capture beneficiary details for contract cover claims. New


ClaimsValidationController will have below endpoints:

/claim-validate POST API to validate each claim line item for pre-defined set of validation rules. New 

/claim-validation-rules GET Get validation rules by claim type and asset type. New 

/validate-result-update POST Capture details about manual validation result, e.g., if arrears check is passed manually. This API should capture details of the same.


ClaimsItemController will have below endpoints:

/claim-item/ POST Create claim line item for given claim. New 

/claim-items POST Create collection of claim line items. New 

/claim-item/{id} GET Get claim line item for given ID. New 

/claim-item/{id} PUT Update claim line item. New 

/claim-item/:claimId/claim-items GET Get all claim line items for passed claim ID. New 

/claim-item/:id/status PATCH Update status and sub-status of claim line item. New


ClaimsDocumentController will have below endpoints:

/document-upload POST API to upload document/evidence for given claim or claim line item. This API will do file extension validations, size validation, and all basic validations needed before uploading file to s3. New 

/document/{id} GET Get document by ID and/or doc type for given claim or claim line item. New 

/document/{id} DELETE Delete document for given claim or claim line item. New 

/document?{type}&{assetType}&claimType GET Get number of documents required to upload as per claim type, asset type, and document type. For example, get number of quotes required for a household asset. New 

/document-download/ POST Download document for given (claim ID / claim line item ID) and s3 link. New 

/document?claimId&documentType GET Get document by document type and claim ID.


Document generation Service: This service is used to generate required documents for claims process. For example, settlement letters and rejection letters in cash claims flow.
